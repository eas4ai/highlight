# Glossary

**Highlighter.** The public service that selects a language and renders source
code through a theme.

**Language.** A registered syntax definition with a canonical name, aliases,
patterns, and optional injections.

**Pattern.** A rule that recognizes a source span and assigns it a token type.

**Injection.** A rule that delegates a source span to another language or
highlighting pass.

**Fixture.** Representative source used by tests, benchmarks, or visual review.

**Fallback.** The plain-text language used when no registered identifier matches.

**Visual harness.** The browser page used to inspect a fixture and capture a
stable screenshot.
